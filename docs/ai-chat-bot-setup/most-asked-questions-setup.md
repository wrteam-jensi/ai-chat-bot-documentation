# Most Asked Questions Setup Guide

This comprehensive guide will help you set up and configure the Most Asked Questions (MAQ) system for your AI chat bot. Learn how to manage frequently asked questions, track question popularity, and improve your chatbot's knowledge base.

## Prerequisites

Before setting up the Most Asked Questions system, ensure you have:
- ✅ Admin panel access with proper permissions
- ✅ AI chat bot system configured and running
- ✅ User conversations and question data available
- ✅ Basic understanding of FAQ management

## Step 1: Access Most Asked Questions

### Navigate to MAQ Section
1. **Login** to your admin panel
2. **Navigate** to Dashboard > Most Asked Questions
3. **View** the main MAQ interface
4. **Familiarize** yourself with the interface layout

### Interface Overview
The MAQ interface includes:
- **Search Bar**: Real-time search functionality
- **Sort Options**: Multiple sorting criteria
- **Data Table**: Comprehensive question and answer management
- **Pagination**: Efficient navigation through large datasets
- **Action Controls**: View and delete operations

## Step 2: Configure Search and Filter

### Search Functionality
1. **Use** the search bar to find specific questions
2. **Type** keywords to search through questions and answers
3. **Review** search results for relevance
4. **Clear** search to return to full list

### Sorting Options
1. **Click** the "Sort By" dropdown
2. **Select** sorting criteria (Default, Date, Popularity, etc.)
3. **Apply** sorting to organize questions
4. **Verify** that sorting is working correctly

## Step 3: Manage Questions

### View Question Details
1. **Click** the eye icon next to any question
2. **Review** the "View FAQ" modal
3. **Check** question and answer content
4. **Close** modal when finished

### Delete Questions
1. **Click** the red trash can icon
2. **Confirm** deletion in the modal dialog
3. **Verify** question is removed from the list
4. **Check** that deletion was successful

### Bulk Operations
1. **Select** multiple questions using checkboxes
2. **Perform** bulk actions on selected questions
3. **Delete** multiple questions at once
4. **Verify** that bulk operations are working

## Step 4: Configure Pagination

### Records Per Page
1. **Click** the "Showing" dropdown
2. **Select** number of records per page (10, 25, 50, 100)
3. **Apply** pagination settings
4. **Verify** that pagination is working correctly

### Page Navigation
1. **Use** previous/next arrows for navigation
2. **Click** page numbers for direct navigation
3. **Check** record count display
4. **Verify** that navigation is working properly

## Step 5: Monitor Question Analytics

### Popularity Tracking
1. **Review** question frequency and popularity

4. **Analyze** user question patterns

### Answer Quality

4. **Plan** improvements for answer quality
