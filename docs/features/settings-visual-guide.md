# Settings Management - Visual Guide

This visual guide provides step-by-step instructions for managing settings using the Settings Management interface. Follow these visual examples to effectively configure AI models and manage languages for your chat bots.

## Overview

The Settings Management system provides comprehensive configuration options for AI chat bots. This visual guide covers all major operations including AI model configuration, language management, and system settings.

## Main Settings Interface

### Settings Dashboard
![Settings UI](../../static/img/ai-feature/setting-ui.png)
*The main Settings interface showing AI model selection and language management sections*

**Key Elements:**
- **Header**: "Settings" title with user profile dropdown
- **AI Model Section**: Configuration for AI model selection
- **Languages Section**: Management of supported languages
- **Success Notifications**: Real-time feedback for operations
- **Action Controls**: Save and cancel operations

## AI Model Configuration

### Step 1: Access Settings
![Settings UI](../../static/img/ai-feature/setting-ui.png)
*Navigate to Dashboard > Settings to access configuration options*

### Step 2: Select AI Model
![Select Model Dropdown](../../static/img/ai-feature/setting-select-modal.png)
*Choose between OpenAI and Gemini models with available options*

**Model Options:**
- **Open AI (Chat GPT)**: Radio button option for OpenAI integration
- **Gemini**: Radio button option for Google Gemini integration
- **API Key Management**: Secure input fields for API keys
- **Model Selection**: Dropdown with extensive model options

### Step 3: Configure API Keys
1. **Enter API Key**: Add your API key for the selected model
2. **Select Model Version**: Choose specific model version
3. **Test Configuration**: Verify API key and model work
4. **Save Settings**: Click "Save" to apply configuration

## Language Management

### Step 1: Access Languages Section
![Settings UI](../../static/img/ai-feature/setting-ui.png)
*View the Languages section with current language configurations*

### Step 2: Add New Language
![Add Language Modal](../../static/img/ai-feature/setting-add-lang.png)
*Click "Add Language" button to open the creation modal*

**Modal Features:**
- **Language Name**: Text input for language name
- **Language Code**: Text input for language code
- **RTL/LTR Selection**: Radio buttons for text direction
- **Default Language**: Radio buttons for default status
- **File Upload**: Drag & drop area for translation files

### Step 3: Fill Language Details
![Fill Details Form](../../static/img/ai-feature/setting-fill-details.png)
*Enter language information and configuration settings*

**Configuration Options:**
- **Language Name**: Enter full language name (e.g., "English")
- **Language Code**: Enter short code (e.g., "en")
- **Text Direction**: Select RTL or LTR
- **Default Status**: Set as default language or not
- **Translation File**: Upload JSON translation file

### Step 4: Upload Translation Files
1. **Drag & Drop**: Drag translation files to upload area
2. **File Selection**: Click "choose file" to browse files
3. **File Validation**: Ensure JSON format is correct
4. **File Management**: Remove or replace uploaded files

### Step 5: Save Language
![Save Modal](../../static/img/ai-feature/setting-save-modal.png)
*Click "Save" to create the new language*

## Language Operations

### Editing Existing Languages
![Edit Language Modal](../../static/img/ai-feature/setting-edit-lang.png)
*Click the pencil icon to edit existing language settings*

**Edit Options:**
- **Modify Details**: Update language name and code
- **Change Settings**: Update RTL/LTR and default status
- **Update Files**: Upload new translation files
- **Download Files**: Access existing translation files

### Deleting Languages
![Delete Language Confirmation](../../static/img/ai-feature/setting-delete-lang.png)
*Click the trash can icon to delete languages*

**Deletion Process:**
1. **Click Delete Icon**: Click the red trash can icon
2. **Confirmation Modal**: "Are you sure you want to delete question?" appears
3. **Confirm Deletion**: Click "Yes, Delete" to confirm
4. **Language Removal**: Language is permanently deleted
