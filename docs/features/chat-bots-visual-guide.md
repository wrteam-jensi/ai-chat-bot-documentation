# Chat Bots Management - Visual Guide

This visual guide provides step-by-step instructions for managing chat bots using the Chat Bots Management interface. Follow these visual examples to effectively manage your AI chat bots.

## Overview

The Chat Bots Management system provides a comprehensive dashboard for managing multiple AI chat bots. This visual guide covers all major operations including viewing, creating, editing, resetting, and deleting chat bots.

## Main Dashboard Interface

### Chat Bots Dashboard
![Chat Bots Dashboard](../../static/img/ai-feature/bot-list.png)
*The main Chat Bots dashboard showing all chat bots with performance metrics and action buttons*

**Key Elements:**
- **Header**: "With Your Chatbots" title with descriptive subtitle
- **Add Button**: Blue "+ Add Chatbot" button for creating new bots
- **Bot Cards**: Grid layout showing all chat bots with performance metrics
- **Action Buttons**: Edit, reset, and delete operations for each bot
- **Status Indicators**: Active (green) and Deactive (red) status tags
- **Performance Graphs**: Blue line graphs showing bot usage over time

## Creating New Chat Bots

### Step 1: Access Create Modal
![Create Bot Modal](../../static/img/ai-feature/bot-create.png)
*Click the blue "+ Add Chatbot" button to open the creation modal*

**Modal Features:**
- **Profile Photo**: Circular blue icon with upload option
- **Bot Name**: Text input with "Enter Bot Name" placeholder
- **Bot Purpose**: Text input with "For Customer Support" placeholder
- **Color Configuration**: Six color fields for customizing bot appearance
- **Action Buttons**: Cancel and Create buttons

### Step 2: Configure Bot Settings
1. **Enter Bot Name**: Provide a descriptive name for your bot
2. **Set Bot Purpose**: Define the bot's primary function
3. **Upload Profile Photo**: Add a custom profile picture (optional)
4. **Configure Colors**: Set color scheme for all bot elements
5. **Click Create**: Create the new bot

## Managing Existing Chat Bots

### Bot Card Information
Each bot card displays:
- **Icon**: Unique robot icon with color coding
- **Name**: Bot name and description
- **Status**: Active (green) or Deactive (red) indicator
- **Performance**: Usage graph and user metrics
- **Actions**: Edit, reset, and delete buttons

### Performance Metrics
- **Usage Graphs**: Blue line graphs showing bot activity over time
- **User Counts**: Track number of users for each bot
- **Activity Indicators**: Visual representation of bot performance
- **Status Updates**: Real-time status information

## Resetting Bot Data

### Step 1: Open Reset Modal
![Reset Bot Modal](../../static/img/ai-feature/bot-reset.png)
*Click the orange "reset" button to open the reset options modal*

**Reset Options:**
- **Delete FAQs**: Remove all FAQ entries
- **Delete Knowledge Hub**: Remove knowledge base content
- **Delete Documents**: Remove uploaded documents
- **Delete Conversation Logs**: Remove chat history

### Step 2: Configure Reset Options
1. **Select Data to Reset**: Choose what data to reset
2. **Review Warning**: Read the warning message carefully
3. **Confirm Reset**: Click the red "Reset" button
4. **Wait for Completion**: Allow the reset process to complete

### Step 3: Verify Reset Success
![Reset Success](../../static/img/ai-feature/bot-reset-sucess.png)
*Green success banner appears after successful reset operation*

**Success Indicators:**
- **Green Banner**: "Chatbot reset successfully!" message
- **Visual Feedback**: Clear indication of successful operation
- **Auto-Dismiss**: Notification disappears automatically
- **Dashboard Update**: Bot data is reset and updated

## Deleting Chat Bots

### Step 1: Initiate Deletion
![Delete Confirmation](../../static/img/ai-feature/bot-delete.png)
*Click the red "Delete" button to open the deletion confirmation modal*

**Deletion Modal Features:**
- **Warning Icon**: Large red trash can icon with X marks
- **Confirmation Text**: "Are you sure you want to delete [Bot Name]?"
- **Action Buttons**: Cancel (white) and "Yes, Delete" (red) buttons
- **Safety Measures**: Clear confirmation required

### Step 2: Confirm Deletion
1. **Review Bot Name**: Verify you're deleting the correct bot
2. **Consider Consequences**: Understand that deletion is permanent
3. **Click "Yes, Delete"**: Confirm the deletion
4. **Wait for Completion**: Allow the deletion process to complete

### Step 3: Verify Deletion Success
![After Delete](../../static/img/ai-feature/bot-after-delete.png)
*Dashboard updates automatically after successful bot deletion*

**Success Indicators:**
- **Bot Removal**: Bot card is removed from dashboard
- **Dashboard Update**: Interface updates automatically
- **Success Notification**: Green banner confirms deletion
- **Clean Interface**: Dashboard shows remaining bots

## Editing Bot Settings

### Accessing Bot Settings
1. **Click Edit Button**: Click the blue "Edit" button on any bot card
2. **Navigate to Settings**: Automatically redirects to bot settings page
3. **Configure Settings**: Access all bot configuration options
4. **Save Changes**: Save and apply configuration changes
5. **Return to Dashboard**: Navigate back to chat bots dashboard
